## Hard deadlines
- **11:30 PM: keyboards down.** Late commits don't count. Hand in the **team slip**.
- **11:35 PM: at our table with the slip and the demo running.** Judges walk to every table.

## Theme: State of Utah
Build something that makes Utah better. Examples include local Utah shops and makers.

## Judging
1. It works (live demo) 2. It's useful (someone in Utah would use it) 3. It's well built 4. It's clear in 3 minutes.
